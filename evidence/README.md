# Evidence

Everything under this folder is captured output, not hand-written analysis — CloudTrail-derived
denial transcripts, and two full Prowler scans (baseline and after) with their per-framework
compliance exports. `prowler-baseline.md` and `scp-findings.md` are the two narrative summaries
that interpret this raw evidence; see `docs/results.md` for the consolidated before/after
comparison. All account, organization, and policy identifiers in this folder have been redacted
before publishing (see the root README's disclaimer).
